# Схемы крипто-скама через Telegram-каналы

Документ для системы KRO: как владельцы каналов могут обманывать подписчиков и зарабатывать.  
Источник данных для детектора: `backend/kro-schemes/schemes.json`.

## Как это работает в проверке канала

1. Система читает **текст ленты** (до 6 месяцев при живой проверке).
2. Каждый пост сверяется со **списком схем** (ключевые слова + Mistral AI).
3. В ответе показывается: **название схемы**, **цитата из поста**, **как автор зарабатывает**, **чем это опасно для вас**.

## Схемы (краткий справочник)

### Памп-дамп
Организаторы заранее покупают низкокапитализированный токен, в канале объявляют «покупаем сейчас», тысячи подписчиков входят, организаторы продают на пике.  
**Красный флаг:** таймер, «buy now», конкретный тикер без анализа.

### VIP / ранний доступ
Платная подписка даёт сигнал раньше публичного канала — инсайдеры уже в сделке.  
**Красный флаг:** цена VIP, «только для закрытой группы».

### Гарантия прибыли
Обещания «100%», «без риска» — в крипте гарантий не бывает.  
**Красный флаг:** нет упоминания стопов и убытков.

### FOMO / срочность
«Последние места», «2 минуты» — чтобы вы не успели проверить.  
**Красный флаг:** дедлайны в каждом посте.

### Скрытие убытков
Только скрины в плюс, иксы x10/x100 — минусы не показывают.  
**Красный флаг:** нет ни одного поста с убыточной сделкой.

### Курсы и наставничество
Дорогое обучение без проверяемой истории сделок на блокчейне.  
**Красный флаг:** нет публичного кошелька / track record.

### Реферальная пирамида
Доход от приглашения друзей важнее торговли.  
**Красный флаг:** многоуровневые бонусы за рефералов.

### Фейковая биржа
Депозит на сайт, баланс «растёт» в интерфейсе, вывод заблокирован.  
**Красный флаг:** торговля только на неизвестной платформе.

### Комиссия за вывод
Просят заплатить «налог», «верификацию», «лицензию» для вывода — классический advance-fee fraud.  
**Красный флаг:** любой дополнительный платёж для разблокировки.

### Pig butchering (разогрев)
Месяцы доверия в личке → крупный депозит → блокировка.  
**Красный флаг:** просьбы скринов, «личный менеджер».

### Фейковые скрины PnL
Картинки прибыли без TX hash на блокчейне.  
**Красный флаг:** скрины без ссылки на Etherscan/Solscan.

### Rug pull
Продвижение своего токена → снятие ликвидности.  
**Красный флаг:** анонимная команда, нет lock liquidity.

### Апрув кошелька
«Подключи кошелёк для верификации» → кража через approve.  
**Красный флаг:** ссылки на неизвестные dApp.

### Фишинг / фейковая поддержка
Пишут первыми, просят seed phrase или код 2FA.  
**Красный флаг:** поддержка в личке, неофициальные боты.

### Обменник без вывода
Выгодный курс → после перевода USDT вывод «на проверке» вечно.  
**Красный флаг:** P2P только через их контакт.

### Инвест-бот (% в день)
Фиксированный процент — признак понци.  
**Красный флаг:** «3% в день» независимо от рынка.

### Копитрейдинг-ловушка
Сигналы только на их платформе с минимальным депозитом $500+.  
**Красный флаг:** нельзя торговать на нормальной бирже.

### Неликвидные «гемы»
Мемкоины с крошечной ликвидностью — продать невозможно.  
**Красный флаг:** контракт без аудита.

### Фейковые розыгрыши
«Отправь 0.1 ETH — получишь 1 ETH».  
**Красный флаг:** просьба отправить крипту «для участия».

### Recovery scam
«Вернём украденное» за аванс — второй обман.  
**Красный флаг:** гарантия возврата за предоплату.

### Воронка free → paid
Бесплатные сигналы слабые, после минусов продают VIP как «спасение».  
**Красный флаг:** апселл сразу после серии убытков.

### Оплата на личный кошелёк
USDT на TRC20 без юрлица — нет защиты.  
**Красный флаг:** реквизиты в постах.

### Фейковый ICO
Whitelist на токен, которого нет на блокчейне.  
**Красный флаг:** срочный пресейл без контракта.

### Реф-ссылка на «биржу»
Фишинговый клон Binance/Bybit по похожему домену.  
**Красный флаг:** только их ссылка, не официальный сайт.

### AI-хайп
«Секретный нейросетевой алгоритм» без воспроизводимых результатов.  
**Красный флаг:** маркетинг AI без прозрачности.

### Накрутка доверия
100k подписчиков, 200 просмотров на пост.  
**Красный флаг:** несоответствие охватов и подписчиков.
