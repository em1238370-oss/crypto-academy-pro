# Технический снапшот сайта (полная фиксация состояния)

**Назначение:** зафиксировать текущее состояние сайта «как есть» — что делает, как делает, какие файлы за что отвечают. Используется как точка отсчёта: при любых изменениях можно сверяться с этим документом и при необходимости возвращаться к описанному состоянию (через git + журнал изменений).

## 1. Что делает сайт (кратко)

- **Главная страница («Крипта без розовых очков»):** лендинг про проверку крипто-гуру и скам-каналов. Hero, живая статистика (LIVE), блоки «типы лоха», слайдер математики, выбор «сигналы / защита», топ-3 скам-каналов, форма «Проверить канал» (по @username или по скрину), форма «Сообщить о разводе». Подписка (оплата криптой/картой), чат-виджет с AI (Mistral).
- **Подсайты:** News (новости), Risk (распределение рисков), Basics (курс основ), Coach (советник). Доступ по ссылкам из шапки.
- **Бэкенд:** Express (Node.js) в `backend/server.js` — раздаёт статику, API для чата, платежей (CryptoCloud, CloudPayments, CoinGate, YooKassa, NOWPayments, Stripe), KRO (проверка каналов, живой счётчик, отчёты, проверка по скрину). Данные KRO: Google Sheets + локальные JSON, при необходимости — Python-скрипты (Telethon, TGStat и т.д.).

## 5. Бэкенд (backend/server.js) — API

- `GET /api/status` — статус доступа пользователя (userId, trial, subscription).
- `POST /api/chat` — запрос к Mistral AI, ответ в чат.
- Платежи:  
  `POST /api/payments/cryptocloud/invoice`, `callback`;  
  `POST /api/payments/cloudpayments/invoice`, `callback`;  
  `POST /api/payments/coingate/invoice`, `callback`;  
  `POST /api/payments/yookassa/invoice`, `callback`;  
  `POST /api/payments/nowpayments/invoice`, `callback`;  
  `POST /api/payments/stripe/invoice`, `webhook`.
- `GET /api/news/dynamic` — данные для блока новостей.
- **KRO:**  
  `GET /api/kro/check?channel=...` — проверка канала (Google Sheets + при необходимости check_once.py);  
  `GET /api/kro/check-exchanger?url=...` — проверка обменника;  
  `POST /api/kro/check-screenshot` — тело JSON с полем `image` (data URL), распознавание канала/обменника по скрину;  
  `GET /api/kro/live-counter` — JSON для главной: channelsToday, totalLost, telegramCount, coursesCount, shockText, top3[]; данные берутся из `backend/data/kro-12h-stats.json` (и при отсутствии — из kro-reference-stats.json или дефолты);  
  `POST /api/kro/report-scam` — приём отчёта о скаме (channel, sumRub, from);  
  `POST /api/kro/update`, `POST /api/update` — приём обновлений от воркеров;  
  `GET /api/kro/daily-stats` — дневная статистика.

Статика раздаётся из корня проекта (parent of backend). Переменные окружения: см. `.env.example` и предупреждения в начале server.js (Mistral, CryptoCloud, CloudPayments, CoinGate, YooKassa, NOWPayments, Stripe, Google, Telegram и т.д.).

## 6. Данные KRO и воркеры

- **kro-12h-stats.json:** формируется/обновляется kro-worker’ами (например run_12h_monitor.py). Содержит поля для главной: channelsToday, totalLost, telegramCount, coursesCount, shockText, top3 (channel, sum, status). Читается в server.js для `/api/kro/live-counter`.
- **Google Sheets:** база скам-каналов (kroSheetId, kroScamBaseRange). Проверка канала: сначала поиск в таблице, при необходимости запуск `check_once.py` (Python3, Telethon, TGStat и т.д.).
- **Документ Source & Data:** обновляется скриптами в kro-worker (update_sources_doc_once.py, patch_sources_doc.py и др.) по расписанию (cron 12 ч и т.д.). Документация: docs/ru/СПЕЦИФИКАЦИЯ_ДОКУМЕНТА_SOURCE_AND_DATA.md и файлы в kro-worker.

## 7. Деплой и окружение

- **Хостинг:** Render.com. Деплой из GitHub (репозиторий crypto-academy-pro, ветка main). После push — автоматическая сборка и запуск (команда старта из package.json / настройки сервиса).
- **Среда:** Node.js, установка зависимостей из backend (или корня — по конфигу Render). Переменные окружения задаются в панели Render (ключи API, Google, Telegram, APP_BASE_URL и т.д.).
- **Возврат к прошлому:** git history + теги/ветки при необходимости; любой набор изменений фиксируется в `docs/ru/ЖУРНАЛ_ВСЕХ_ИЗМЕНЕНИЙ.md` с указанием коммита (hash) и списка затронутых файлов.
