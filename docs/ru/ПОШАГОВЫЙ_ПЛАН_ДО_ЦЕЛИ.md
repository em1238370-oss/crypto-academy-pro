# Пошаговый план: от ошибки до цели

Цель: при нажатии «Проверить» любой канал (из базы или по ссылке) давал результат без «ошибки сервера».

---

## Шаг 1. Переменные на Render (делаешь ты)

**Где:** https://dashboard.render.com → твой сервис → **Environment**.

**Важно:** в `KRO_SHEET_ID` часто путают букву **l** и цифру **1**.

- Правильный ID таблицы: `1C1NQwqmLRg59**xgplnz5**PeghRxaR_**YY2lf**SWZAJae6qM`
  - в середине: **xgplnz5** (латинская L в xgp**l**nz5);
  - в конце части: **YY2lf** (латинская L в YY2**l**f).

**Проверь и сохрани такие переменные:**

| Переменная | Значение |
|------------|----------|
| `KRO_SHEET_ID` | `1C1NQwqmLRg59xgplnz5PeghRxaR_YY2lfSWZAJae6qM` |
| `KRO_GOOGLE_CREDENTIALS_JSON` | Весь JSON сервисного аккаунта **одной строкой** |
| `KRO_SCAM_BASE_RANGE` | `scam_base!A2:H` |
| `KRO_CHECK_QUEUE_RANGE` | `check_queue!A2:B` (по желанию) |

Нажми **Save Changes**. Деплой перезапустится сам.

## Шаг 2. Доступ к Google Таблице (делаешь ты)

**Где:** https://docs.google.com/spreadsheets/d/1C1NQwqmLRg59xgplnz5PeghRxaR_YY2lfSWZAJae6qM/edit

1. Открой таблицу → **Поделиться**.
2. Добавь **email** из JSON (поле **client_email**, вид `...@....iam.gserviceaccount.com`) с правом **Редактор**.
3. Сохрани.

Без этого сервер не прочитает scam_base.

---

## Шаг 3. Лист scam_base (делаешь ты)

В той же таблице:

1. Второй лист должен называться **scam_base**. Если он «Лист 2» — в Render в `KRO_SCAM_BASE_RANGE` укажи: `Лист 2!A2:H`.
2. Строка 1 — заголовки: **username**, **risk_score**, **ads_per_week**, **bot_pct**, **vip_price**, **complaints**, **total_loss**, **verdict** (колонки A–H).
3. Со строки 2 — хотя бы один канал (например в A: `@TONPumpKing`, в B: `87`, в H: `scam`).

---

## Шаг 4. Проверка (делаешь ты)

1. Дождись окончания деплоя на Render (1–2 мин).
2. Открой сайт, введи канал из базы (например `@TONPumpKing`) → **Проверить**.

Должны появиться риск, причины, потери, вердикт. Если снова ошибка — текст на экране или в **Logs** на Render подскажет, что поправить (например «Не удалось прочитать базу» → шаги 1–2).

---

## Шаг 5. Любой канал, не только из базы (опционально)

Сейчас каналы **не из базы** попадают в очередь; результат приходит после воркера или при повторном «Проверить» через 1–2 минуты.

Чтобы **любой** канал сразу давал результат на Render без воркера:

- Переключи сервис на **Docker** (в настройках Render) и настрой сессию Telegram по инструкции:  
  **docs/ru/RENDER_DOCKER_ЛЮБОЙ_КАНАЛ.md**

Или запускай воркер у себя на ПК (см. **backend/kro-worker/README.md**) — тогда каналы из очереди обработаются, и при повторной проверке результат появится.
