# Итоговые значения для публикации (Блок 5) — формат для сайта

После заполнения отчёта SOURCE & DATA (по [ОТЧЁТ_SOURCE_AND_DATA_СПЕЦИФИКАЦИЯ.md](ОТЧЁТ_SOURCE_AND_DATA_СПЕЦИФИКАЦИЯ.md); компактная структура отчёта за цикл — в [СТРУКТУРА_ОТЧЁТА_ЦИКЛ_7_БЛОКОВ.md](СТРУКТУРА_ОТЧЁТА_ЦИКЛ_7_БЛОКОВ.md)) блок **«Итоговые значения для публикации»** нужно перенести в машиночитаемый формат, чтобы главная страница сайта показывала актуальные цифры.

## Куда вставить данные

**Файл:** `backend/data/kro-12h-stats.json`

Сервер при запросе `/api/kro/live-counter` сначала проверяет этот файл. Если он есть и содержит валидные данные за последний 12‑часовой цикл — на сайт отдаются они. Если файла нет или он устарел — используются данные из Google Sheets (лист «Отчёты») или запасные значения.

## Формат JSON

Структура файла `kro-12h-stats.json`:

| Поле | Тип | Описание |
|------|-----|----------|
| `new_scams` | число | Новых скам‑каналов за период (из каналов со статусом «ПРОШЁЛ ФИЛЬТР») |
| `losses_12h` | число | Суммарные потери за период, ₽ |
| `complaints_count` | число | Количество учтённых жалоб |
| `top3` | массив | Ровно 3 элемента: `{ "channel": "название или @username", "sum": число_руб, "status": "Активен" \| "Удалён" \| "Блок" }` |
| `telegram_channels` | число, опционально | Telegram каналов (для карточки на сайте) |
| `courses` | число, опционально | Курсы фейк-продуктов (для карточки на сайте) |
| `period_start` | строка, опционально | Начало периода: `DD.MM.YYYY HH:MM` (MSK) |
| `period_end` | строка, опционально | Конец периода: `DD.MM.YYYY HH:MM` (MSK) |
| `updatedAt` или `timestamp` | строка | Когда значения обновлены (ISO 8601 или любая метка времени) |

Поле `status` в элементах `top3` на сайте отображается как есть; по нему выбирается стиль (Активен / Удалён / Блок).

## Пример минимального файла

```json
{
  "new_scams": 12,
  "losses_12h": 292000,
  "complaints_count": 7,
  "top3": [
    { "channel": "@MoonPumpVIP", "sum": 147000, "status": "Активен" },
    { "channel": "crypto-fast.pro", "sum": 98000, "status": "Блок" },
    { "channel": "@TONVIPnew", "sum": 0, "status": "Активен" }
  ],
  "telegram_channels": 37,
  "courses": 10,
  "period_start": "02.03.2026 00:00",
  "period_end": "02.03.2026 12:00",
  "updatedAt": "2026-03-02T11:59:00+03:00"
}
```

## Как обновить файл после отчёта

1. Откройте отчёт SOURCE & DATA и найдите блок **«Итоговые значения для публикации»**.
2. Перенесите значения в JSON по полям выше (числа — без пробелов и кавычек в сумме, `top3` — три объекта с `channel`, `sum`, `status`).
3. Сохраните (или вставьте) результат в `backend/data/kro-12h-stats.json` в репозитории и задеплойте, **либо** положите файл на сервер в каталог `backend/data/` (если у вас есть доступ к файловой системе сервера).
4. Главная страница при следующей загрузке подхватит новые данные (кэш не хранится долго).

Скрипт `run_12h_monitor.py` при запуске тоже пишет в этот файл; если вы ведёте отчёт вручную по спецификации, достаточно перезаписать файл после заполнения Блока 5.
