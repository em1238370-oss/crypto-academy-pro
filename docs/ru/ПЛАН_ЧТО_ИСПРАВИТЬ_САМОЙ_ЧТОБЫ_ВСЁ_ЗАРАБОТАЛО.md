## 1. Переменные на Render

**Где:** https://dashboard.render.com → сервис **crypto-academy-pro** → вкладка **Environment**.

**Сделай:**

- Убедись, что переменные называются **точно так** (не KRU, не SCAN):
  - `KRO_SHEET_ID`
  - `KRO_GOOGLE_CREDENTIALS_JSON`
  - `KRO_SCAM_BASE_RANGE`
  - `KRO_CHECK_QUEUE_RANGE`
- Задай значения:
  - **KRO_SHEET_ID:** `1C1NQwqmLRg59xgplnz5PeghRxaR_YY2lfSWZAJae6qM`
  - **KRO_GOOGLE_CREDENTIALS_JSON:** весь JSON сервисного аккаунта **одной строкой** (открой скачанный .json в блокноте, скопируй всё, убери переносы строк, вставь в значение переменной).
  - **KRO_SCAM_BASE_RANGE:** `scam_base!A2:H` (если второй лист в таблице называется иначе — подставь его имя, например `Лист 2!A2:H`).
  - **KRO_CHECK_QUEUE_RANGE:** `check_queue!A2:B`
- Нажми **Save Changes**. Render сделает новый деплой.

## 2. Доступ к Google Таблице

**Где:** https://docs.google.com/spreadsheets/d/1C1NQwqmLRg59xgplnz5PeghRxaR_YY2lfSWZAJae6qM/edit

**Сделай:**

1. Открой таблицу.
2. Нажми **Поделиться** (справа вверху).
3. В поле «Добавить пользователей» вставь **email** из JSON сервисного аккаунта (поле **client_email**; вид `что-то@что-то.iam.gserviceaccount.com`).
4. Выбери право доступа **Редактор**.
5. Сохрани.

Без этого сервер не сможет читать листы scam_base и Отчёты.

## 3. Лист scam_base в таблице

**Где:** та же таблица, второй лист.

**Сделай:**

1. Убедись, что лист называется **scam_base** (или запомни точное имя и укажи его в `KRO_SCAM_BASE_RANGE` на Render, например `Лист 2!A2:H`).
2. В первой строке должны быть заголовки: **username**, **risk_score**, **ads_per_week**, **bot_pct**, **vip_price**, **complaints**, **total_loss**, **verdict** (в колонках A–H).
3. Со второй строки — хотя бы одна строка с каналом. Пример: в A — `@TONPumpKing`, в B — `87`, в C — `14`, в D — `78%`, в E — `7000₽`, в F — `23`, в G — `2.1млн₽`, в H — `scam`.

После этого проверка по этому каналу должна находить его в базе и показывать риск, причины, потери, вердикт.

## 4. Проверка после исправлений

1. Дождись окончания деплоя на Render (1–2 минуты после сохранения Environment).
2. Открой сайт (например https://crypto-academy-pro.onrender.com).
3. В блоке «Проверить канал» введи канал, который есть в scam_base (например `@TONPumpKing`), нажми **Проверить**.

Должны появиться: риск X/100, причины, потери пользователей, вердикт. Если снова будет ошибка — в интерфейсе или в логах Render (вкладка Logs у сервиса) будет видно уточнённое сообщение — по нему можно понять, что ещё поправить.
