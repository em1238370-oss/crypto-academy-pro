# Что мне нужно сделать пошагово — чтобы достичь цели

**Цель:** человек из интернета вставляет на сайт любой Telegram-канал (связанный с криптой) → сразу идёт проверка по сообщениям и показывается результат (риск, вердикт). Каналы не про крипту мы не проверяем — показываем сообщение.

Ниже — что **тебе** нужно принести, подключить и настроить. Всё по шагам.

---

## Что тебе понадобится (список)

1. **Google: сервисный аккаунт** — JSON-файл с ключами (чтобы сайт читал/писал таблицу).
2. **Google Таблица** — твоя таблица с листом `scam_base`; ты даёшь доступ сервисному аккаунту.
3. **Render: переменные** — в Environment вставляешь ID таблицы, JSON одной строкой, имена листов.
4. **Telegram: API** — `API ID` и `API Hash` с my.telegram.org (чтобы живая проверка каналов работала).
5. **Telegram: сессия** — один раз войти в Telegram на своём компе, получить файл `kro_worker.session` и загрузить его в Render как Secret File.
6. **Render: Docker** — переключить сервис на Docker, чтобы на сервере работал и Node, и Python (Telethon).

Без пунктов 1–3 проверка по таблице не заработает. Без 4–6 «любой канал из интернета» не будет проверяться сразу — только из базы или через очередь/воркер.

---

## Шаг 1. Google — сервисный аккаунт (ключи для таблицы)

**Что сделать:** получить JSON с ключами от Google.

1. Зайди: https://console.cloud.google.com/
2. Создай проект или выбери существующий.
3. **APIs & Services** → **Credentials** → **Create Credentials** → **Service account**.
4. Дай имя (например `kro-sheets`), создай. Открой созданный аккаунт → вкладка **Keys** → **Add Key** → **Create new key** → **JSON** → скачай файл.
5. Открой скачанный JSON в блокноте. Тебе нужны:
   - **client_email** — вида `xxx@xxx.iam.gserviceaccount.com` (его потом добавишь в доступ к таблице).
   - Весь JSON **одной строкой** (можно скопировать и в блокноте убрать переносы) — это вставишь в Render в переменную `KRO_GOOGLE_CREDENTIALS_JSON`.

**Что принести:** файл `.json` и знание, где в нём `client_email`.

---

## Шаг 2. Google Таблица — доступ и лист scam_base

**Что сделать:** дать таблице правильное имя листа и доступ сервисному аккаунту.

1. Открой таблицу:  
   https://docs.google.com/spreadsheets/d/1C1NQwqmLRg59xgplnz5PeghRxaR_YY2lfSWZAJae6qM/edit  
   (или свою, тогда запомни её ID из ссылки: `/d/***ID***/edit`.)

2. **Поделиться** (кнопка справа вверху) → в поле «Добавить пользователей» вставь **client_email** из JSON (шаг 1) → право доступа **Редактор** → сохрани.

3. Второй лист назови **scam_base** (или запомни точное имя, например «Лист 2»).  
   В первой строке листа заголовки: **username**, **risk_score**, **ads_per_week**, **bot_pct**, **vip_price**, **complaints**, **total_loss**, **verdict** (колонки A–H). Со второй строки — данные по каналам (хотя бы одна строка для проверки).

**Что принести:** ничего, просто сделать. ID таблицы и имя листа понадобятся в Render.

---

## Шаг 3. Render — переменные окружения (подключить таблицу)

**Что сделать:** вставить в Render ключи и настройки таблицы.

1. Зайди: https://dashboard.render.com → выбери сервис (crypto-academy-pro или как у тебя).
2. Вкладка **Environment**. Добавь/исправь переменные (имена **точно** такие):

| Переменная | Что вставить |
|------------|----------------|
| `KRO_SHEET_ID` | ID таблицы из ссылки Google (например `1C1NQwqmLRg59xgplnz5PeghRxaR_YY2lfSWZAJae6qM`). Не путай букву **l** и цифру **1**: в середине **xgplnz5**, в конце **YY2lf**. |
| `KRO_GOOGLE_CREDENTIALS_JSON` | Весь JSON из шага 1 **одной строкой** (без переносов). |
| `KRO_SCAM_BASE_RANGE` | `scam_base!A2:H` (если лист называется иначе — подставь его имя, например `Лист 2!A2:H`). |
| `KRO_CHECK_QUEUE_RANGE` | `check_queue!A2:B` (по желанию). |

3. **Save Changes**. Дождись деплоя (1–2 минуты).

После этого проверка по каналам из таблицы должна работать. Чтобы проверять **любой** канал из интернета сразу — делай шаги 4–6.

---

## Шаг 4. Telegram — API ID и API Hash (ключи для живой проверки)

**Что сделать:** получить ключи приложения в Telegram.

1. Зайди: https://my.telegram.org (войди по номеру телефона).
2. **API development tools** → создай приложение (название можно любое). Скопируй:
   - **api_id** (число),
   - **api_hash** (строка).

**Что принести:** эти два значения — их вставишь в Render в шаге 6.

---

## Шаг 5. Telegram — сессия (один раз войти, получить файл)

**Что сделать:** один раз войти в Telegram на своём компьютере, чтобы создался файл сессии.

1. На своём компе открой терминал, перейди в папку проекта:
   ```bash
   cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1/backend/kro-worker"
   ```
2. Запусти (подставь свои api_id и api_hash из шага 4):
   ```bash
   TELEGRAM_API_ID=12345678 TELEGRAM_API_HASH=твой_api_hash python3 check_once.py @durov
   ```
3. Введи номер телефона (в формате +7...) и код из Telegram, когда попросит. После успешного входа в папке появится файл **kro_worker.session**.

**Что принести:** файл `kro_worker.session` из папки `backend/kro-worker`. Его нужно будет загрузить в Render как Secret File (шаг 6).

---

## Шаг 6. Render — Docker, Telegram-переменные и сессия (живая проверка любого канала)

**Что сделать:** включить Docker, добавить ключи Telegram и файл сессии.

1. **Render** → твой сервис → **Settings** → **Environment** выбери **Docker**. Сохрани (Render начнёт собирать образ из Dockerfile).

2. Вкладка **Environment** (переменные). Добавь:
   - `TELEGRAM_API_ID` — число из шага 4 (api_id).
   - `TELEGRAM_API_HASH` — строка из шага 4 (api_hash).

3. В **Environment** найди блок **Secret Files** → **Add Secret File**:
   - **Filename:** укажи путь к файлу сессии в контейнере. Попробуй сначала: `backend/kro-worker/kro_worker.session`. Если Render просит полный путь: `/app/backend/kro-worker/kro_worker.session`.
   - **Contents:** открой файл `kro_worker.session` с твоего компа (из шага 5). Render обычно позволяет загрузить файл или вставить содержимое — загрузи этот файл.

4. **Save Changes**. Дождись деплоя.

После этого на сайте при вставке **любого** Telegram-канала (связанного с криптой) должна сразу идти проверка по сообщениям и показываться результат. Каналы не про крипту будут с сообщением: «Мы проверяем только каналы, связанные с криптой/скрипторием».

## Краткая сводка — что куда

| Что | Где взять / что сделать | Куда вставить |
|-----|-------------------------|---------------|
| JSON сервисного аккаунта | Google Cloud Console → Credentials → Service account → Key (JSON) | Render: `KRO_GOOGLE_CREDENTIALS_JSON` (одной строкой) |
| client_email | Из того же JSON | Google Таблица → Поделиться → добавить с правом Редактор |
| ID таблицы | Ссылка на таблицу: часть после `/d/` и до `/edit` | Render: `KRO_SHEET_ID` |
| Имя листа с каналами | Ты назвала лист (scam_base или «Лист 2») | Render: `KRO_SCAM_BASE_RANGE` = `scam_base!A2:H` или `Лист 2!A2:H` |
| api_id, api_hash | my.telegram.org → API development tools | Render: `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` |
| Файл сессии | Локально: `python3 check_once.py @durov` в backend/kro-worker | Render: Secret File `backend/kro-worker/kro_worker.session` |
| Docker | В настройках сервиса Render | Settings → Environment → Docker |

Если что-то не заработает — текст ошибки на сайте или в **Logs** на Render подскажет, на каком шаге споткнулись (таблица, доступ, имя листа, Telegram, сессия).
