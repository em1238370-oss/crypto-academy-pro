# Журнал изменений дизайна и вёрстки

**Назначение:** точечная фиксация каждого изменения по дизайну и вёрстке. При следующих правках опираться на этот журнал, чтобы **не задевать другие части сайта**.

**Все изменения (не только дизайн)** записываются в [ЖУРНАЛ_ВСЕХ_ИЗМЕНЕНИЙ.md](./ЖУРНАЛ_ВСЕХ_ИЗМЕНЕНИЙ.md). Полное техническое описание текущего состояния сайта — в [ТЕХНИЧЕСКИЙ_СНАПШОТ_САЙТА.md](./ТЕХНИЧЕСКИЙ_СНАПШОТ_САЙТА.md).

---

## Правила правок (как мы работаем)

1. **Один запрос — одна зона.** Перед правкой определяем: какой именно блок/секция/файл затрагивается (например: только hero, только карточки статистики, только форма «Проверить канал»).
2. **Селекторы и область.** В CSS и HTML меняем только те классы/элементы, которые относятся к задаче. Не трогаем глобальные стили (`*`, `body`, общие переменные), если задача этого не требует.
3. **После каждого изменения** — новая запись в этом журнале: дата, файл, что именно изменено (селектор/блок), суть правки.
4. **Перед правкой** — по возможности смотреть журнал: не пересекается ли новая задача с уже описанными зонами.

---

## Формат записи

Каждая запись содержит:

- **Дата** (ГГГГ-ММ-ДД)
- **Файл(ы):** путь относительно корня проекта
- **Зона:** класс(ы) CSS или фрагмент HTML (id/класс секции)
- **Что сделано:** кратко, что изменено (до/после или описание)
- **Зачем:** чтобы при следующих правках не менять эту зону по ошибке
