# Откуда берутся цифры и отзывы — источники и ссылки

Этот документ перечисляет **все источники данных**, которые используются для блока «живой счётчик» и «за 12 часов» на сайте: откуда мы берём каналы, потери, жалобы и как вы можете сами проверить ссылки.

---

## 1. Основные цифры (главная страница)

### Таблица «Отчёты» (Google Sheets)

- **Что это:** ваша таблица с жалобами и отчётами. Колонки: дата, канал, сумма ₽, тип, статус, от кого.
- **Откуда цифры:** количество каналов за день, сумма потерь, топ-3 по сумме, число жалоб за 24 часа — всё считается по строкам листа «Отчёты».
- **Ссылка:** ваша таблица (ID задаётся в настройках). Формат: `https://docs.google.com/spreadsheets/d/<KRO_SHEET_ID>/edit` — подставьте свой ID таблицы.

Когда таблица настроена и в ней есть данные, приоритет у неё; подпись под счётчиком: «Данные из вашей таблицы (отчёты и жалобы)».

---

### Резервные источники (если таблица пуста или недоступна)

Скрипт `fetch_live_stats.py` обновляет файл `kro-reference-stats.json`. Он берёт данные из следующих открытых источников:

| Источник | Ссылка | Что берём |
|----------|--------|-----------|
| **Vklader — чёрный список Telegram** | https://vklader.com/blacklist-telegram/ | Список каналов/чатов в чёрном списке; считаем уникальные @ и t.me для метрики «Telegram каналов». |
| **TGRev — скам-каналы Telegram** | https://tgrev.ru/scam-telegram-channel | То же: каналы из списка скамов; считаем для «Telegram каналов» и учёта в топе. |

Подпись в этом случае: «Данные из интернета: vklader, tgrev. Обновлено …»

## 2. Блок «За 12 часов» (автоотчёт)

Скрипт `run_12h_monitor.py` каждые 12 часов (01:00 и 13:00 MSK) собирает данные из трёх источников и формирует отчёт в Google Docs. Ниже — прямые ссылки на эти источники.

### TGStat — поиск каналов по запросу «криптовалюта»

- **Что это:** сервис статистики Telegram-каналов. Используется API (поиск каналов, статистика по каналу).
- **Ссылки:**
  - Сайт TGStat: **https://tgstat.ru**
  - API (документация): **https://tgstat.ru/docs/ru/api**
  - Метод, который мы вызываем: поиск каналов `channels/search` (запрос «криптовалюта», country=ru, limit=100), сортировка по новизне (`created_at`). По нему отбираются «новые» каналы за последние 7 дней.
- **Что берём:** список каналов (название, дата создания, ссылка, при возможности рост подписчиков) для блока «Новые каналы» в отчёте.

---

### Telega.io — каталог крипто-каналов

- **Что это:** каталог каналов и чатов Telegram по темам.
- **Прямая ссылка на раздел «Криптовалюты»:**  
  **https://telega.io/catalog/cryptocurrencies**
- **Что берём:** парсинг страницы каталога: ссылки на каналы (t.me/…, @username). Список объединяется с результатами TGStat для отчёта «Новые каналы». Запросы делаются с задержками и нормальным User-Agent.

---

### Telegram — чаты с жалобами и отзывами

- **Что это:** публичные каналы/чаты из списка `KRO_SOURCE_CHANNELS` (настраиваются в окружении). В них люди пишут о скаме, потерях, «слил на пампе» и т.п.
- **Как получаем:** скрипт подключается к Telegram через Telethon (официальный API Telegram), читает сообщения за последние 12 часов, извлекает упоминания каналов и суммы потерь (в т.ч. форматы вроде «47к», «1.2млн»).
- **Ссылки:**
  - Telegram: **https://telegram.org**
  - Документация для разработчиков (API): **https://core.telegram.org**
- **Что берём:** каналы-нарушители, суммы потерь, число постов/жалоб за 12 ч — для блоков «Жалобы» и «Пострадавшие» в отчёте и для критерия «≥2 жалобы → скам».

---

### Лист «Отчёты» (та же Google-таблица)

- **Что это:** тот же лист, куда пользователи и бот отправляют жалобы через форму и команду `/report`.
- **Что берём за 12 ч:** строки за последние 12 часов (по дате в колонке A); группировка по каналу, суммы потерь, количество жалоб. Если по каналу ≥2 жалоб — помечаем как «Скам» в отчёте.

---

## 3. Где посмотреть готовый отчёт за 12 часов

- После каждого запуска `run_12h_monitor.py` создаётся документ в Google Docs с заголовком вида «1 МАРТА 13:51 — АВТООТЧЁТ №14».
- Ссылка на последний отчёт сохраняется в данных для сайта и показывается в блоке «За 12 часов» как **«Отчёт за 12 ч»** (если он есть). Точный URL приходит из API `GET /api/kro/daily-stats` в поле `report_doc_url`.
