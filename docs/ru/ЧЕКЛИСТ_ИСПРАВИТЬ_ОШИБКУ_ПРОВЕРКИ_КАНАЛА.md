# Чек-лист: исправить ошибку «Ошибка сервера при проверке канала»

Если при нажатии «Проверить» появляется ошибка сервера или сообщение о недоступности базы — пройди по шагам ниже. Код уже возвращает понятные сообщения; по ним можно понять, что поправить.

---

## 1. Переменные на Render

**Где:** Render → сервис **crypto-academy-pro** → **Environment**.

Проверь, что переменные называются **именно так** (не KRU, не SCAN):

| Переменная | Значение |
|------------|----------|
| `KRO_SHEET_ID` | `1C1NQwqmLRg59xgplnz5PeghRxaR_YY2lfSWZAJae6qM` |
| `KRO_GOOGLE_CREDENTIALS_JSON` | Весь JSON сервисного аккаунта **одной строкой** (без переносов) |
| `KRO_SCAM_BASE_RANGE` | `scam_base!A2:H` |
| `KRO_CHECK_QUEUE_RANGE` | `check_queue!A2:B` (по желанию) |

Если были `KRU_*` или `KRO_SCAN_BASE_RANGE` — переименуй в `KRO_*` и `KRO_SCAM_BASE_RANGE`. После изменений сохрани (Render сделает новый деплой).

---

## 2. Имя листа в таблице

Таблица: https://docs.google.com/spreadsheets/d/1C1NQwqmLRg59xgplnz5PeghRxaR_YY2lfSWZAJae6qM/edit

Второй лист должен называться **scam_base**. Если он называется иначе (например, «Лист 2»), в Render в `KRO_SCAM_BASE_RANGE` укажи это имя: `Лист 2!A2:H` (без пробела после `!`).

---

## 3. Доступ к таблице для сервисного аккаунта

- Открой таблицу → **Поделиться**.
- Добавь email из JSON сервисного аккаунта (поле **client_email**, вид `xxx@xxx.iam.gserviceaccount.com`) с правом **Редактор**.

Без этого сервер не сможет прочитать scam_base.

---

## 4. Лист scam_base: структура и данные

- **Строка 1:** заголовки: username, risk_score, ads_per_week, bot_pct, vip_price, complaints, total_loss, verdict.
- **Со строки 2:** данные по каналам (хотя бы одна строка для проверки).
- **Колонки A–H:** соответствуют полям выше. Для проверки «@TONPumpKing» в колонке A — username, в B — число риска, в C–H — реклама, боты, VIP, жалобы, потери, вердикт.

---

## После исправлений

Сделай новый деплой (или дождись авто-деплоя после сохранения Environment). Проверь канал снова. Если ошибка останется — в интерфейсе или в логах Render будет видно уточнённое сообщение (например, про диапазон или доступ к таблице).
