# News Design Variants

Five visual variants for the News page. Switch by changing the active `<link>` in `index.html`.

| Variant | File | Style |
|---------|------|-------|
| 1. Minimalist Edge | variant-1-minimalist.css | Bloomberg/FT — less decor, flat cards |
| 2. Editorial Refinement | variant-2-editorial.css | Magazine — dividers, accent lines |
| 3. Dark Premium | variant-3-dark-premium.css | Matches main page — dark bg, purple/gold |
| 4. Warm Minimal | variant-4-warm-minimal.css | Calm — no grid, softer hovers |
| 5. Tactile Depth | variant-5-tactile.css | Premium print — layered shadows, depth |

To use a variant: uncomment its `<link>` in `index.html` and comment out the current one.
