# 📦 Пошаговая инструкция: Перенос через GitHub

## ✅ ШАГ 1: Убедитесь, что всё сохранено на GitHub

### На текущем компьютере (этот):

1. **Откройте GitHub Desktop** (или используйте терминал)
2. **Проверьте, что все изменения запушены:**
   - В GitHub Desktop: должна быть зеленая галочка "All changes pushed"
   - Или в браузере на GitHub: последний коммит должен быть "Add transfer instructions..."

3. **Если есть незапушенные изменения:**
   - В GitHub Desktop: нажмите "Push origin"
   - Или в терминале:
     ```bash
     cd /Users/macmini/crypto-website
     git push origin main
     ```

---

## 🚀 ШАГ 2: На новом компьютере

### 1. Установите необходимые программы:

**Node.js:**
- Скачайте с https://nodejs.org/
- Установите версию LTS (рекомендуется)

**Git:**
- На Mac: обычно уже установлен
- Проверьте: откройте Terminal и введите `git --version`
- Если нет: установите через Homebrew или скачайте с https://git-scm.com/

**GitHub Desktop (опционально, но удобно):**
- Скачайте с https://desktop.github.com/
- Войдите в свой GitHub аккаунт

---

### 2. Склонируйте проект:

**Вариант A: Через GitHub Desktop (проще):**
1. Откройте GitHub Desktop
2. Нажмите "File" → "Clone Repository"
3. Найдите "crypto-academy-pro"
4. Выберите папку, куда клонировать (например, Desktop)
5. Нажмите "Clone"

**Вариант B: Через Terminal:**
```bash
# Перейдите в нужную папку (например, Desktop)
cd ~/Desktop

# Склонируйте репозиторий
git clone https://github.com/em1238370-oss/crypto-academy-pro.git

# Перейдите в папку проекта
cd crypto-academy-pro
```

---

### 3. Установите зависимости:

```bash
# В папке проекта выполните:
npm install
```

Это установит все необходимые пакеты (может занять несколько минут).

---

### 4. Создайте файл `.env`:

**⚠️ ВАЖНО:** Файл `.env` НЕ хранится в Git (для безопасности ключей)!

**Скопируйте файл `.env` с текущего компьютера:**
- Путь: `/Users/macmini/crypto-website/.env`
- Скопируйте его на USB/в облако/отправьте себе на email
- На новом компьютере создайте файл `.env` в корне проекта

**Или создайте новый `.env` файл вручную:**

1. В папке проекта создайте файл `.env`
2. Скопируйте туда все ключи из старого `.env`:

```env
# API Keys
MISTRAL_API_KEY=ваш_ключ_здесь
LIVECOINWATCH_API_KEY=ваш_ключ_здесь

# Payment Providers
NOWPAYMENTS_API_KEY=ваш_ключ_здесь
NOWPAYMENTS_IPN_SECRET=ваш_секрет_здесь

# Server
PORT=4000
NODE_ENV=production
```

---

### 5. Запустите проект:

```bash
# В папке проекта:
npm start
```

Проект должен запуститься на `http://localhost:4000`

## 🆘 Если что-то не работает:

1. **Ошибка "npm: command not found":**
   - Установите Node.js с https://nodejs.org/

2. **Ошибка "git: command not found":**
   - Установите Git с https://git-scm.com/

3. **Ошибка при `npm install`:**
   - Убедитесь, что вы в папке проекта
   - Попробуйте: `rm -rf node_modules package-lock.json && npm install`

4. **Проект не запускается:**
   - Проверьте файл `.env` - все ключи должны быть заполнены
   - Проверьте, что порт 4000 свободен
