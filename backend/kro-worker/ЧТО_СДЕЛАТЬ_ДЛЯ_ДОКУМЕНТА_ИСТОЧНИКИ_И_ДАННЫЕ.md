# Что сделать, чтобы документ «Источники и данные» работал

Скрипт уже настроен: при запуске он проверяет **три сайта** (TGStat, Telega.io/Telega.in, чаты Telegram) и записывает результат в Google Doc «Источники и данные». Ниже — что нужно сделать **вам**, по шагам.

---

## Шаг 1. Создать документ в Google

1. Откройте [Google Диск](https://drive.google.com).
2. Нажмите **«Создать»** → **«Документ Google»** → **«Пустой документ»**.
3. Назовите документ, например: **«KRO: источники и данные»** (или как вам удобно).
4. Сохраните документ (Ctrl+S / Cmd+S).

**Важно:** оставьте документ пустым или с любым текстом — скрипт при первом запуске полностью заменит содержимое.

---

## Шаг 2. Узнать ID документа

1. Откройте этот документ в браузере.
2. Посмотрите на адресную строку. URL будет таким:
   ```
   https://docs.google.com/document/d/XXXXXXXXXXXXXXX/edit
   ```
3. Скопируйте часть **между** `/d/` и `/edit` — это и есть **ID документа**.  
   Пример: если URL такой — `https://docs.google.com/document/d/1abc2def3ghi4jkl/edit` — то ID = `1abc2def3ghi4jkl`.

Запишите этот ID — он понадобится в шаге 4.

---

## Шаг 3. Дать доступ сервисному аккаунту Google

Скрипт подключается к Google Docs от имени «сервисного аккаунта». Этому аккаунту нужен доступ к документу.

1. Найдите файл с ключом Google (часто это `credentials.json` или `kro-google-credentials.json` в папке `backend/kro-worker` или в корне проекта).
2. Откройте этот JSON-файл в блокноте.
3. Найдите строку **`"client_email"`**. Там будет что-то вроде:
   ```
   "client_email": "kro-worker@ваш-проект.iam.gserviceaccount.com"
   ```
4. Скопируйте этот **email** (целиком).
5. Откройте ваш документ «Источники и данные» в Google.
6. Нажмите кнопку **«Настройки доступа»** (или «Поделиться») в правом верхнем углу.
7. В поле «Добавить пользователей» вставьте скопированный email сервисного аккаунта.
8. Выберите право **«Редактор»**.
9. Снимите галочку «Уведомить пользователей», если не хотите отправлять письмо.
10. Нажмите **«Готово»** (или «Отправить»).

Без этого шага скрипт не сможет записать в документ.

---

## Шаг 4. Прописать ID документа в настройках проекта

1. Откройте папку вашего проекта на компьютере.
2. Найдите файл с переменными окружения:
   - либо `backend/kro-worker/env`,
   - либо `backend/kro-worker/.env`,
   - либо `.env` в корне проекта.
3. Откройте этот файл в блокноте.
4. Добавьте строку (подставьте **ваш** ID из шага 2):
   ```
   KRO_SOURCES_DOC_ID=ваш_id_документа
   ```
   Пример: если ID = `1abc2def3ghi4jkl`, то строка:
   ```
   KRO_SOURCES_DOC_ID=1abc2def3ghi4jkl
   ```
5. Сохраните файл.

---

## Шаг 5. Убедиться, что остальные переменные заданы

Для работы с **тремя источниками** скрипту нужны ещё переменные. Проверьте, что в том же файле `env` / `.env` есть:

| Переменная | Зачем нужна |
|------------|-------------|
| `KRO_GOOGLE_CREDENTIALS_JSON` | Или путь к `credentials.json` — доступ к Google Docs. |
| `TGSTAT_API_KEY` | Ключ API TGStat — чтобы брать каналы с tgstat.ru. |
| `KRO_SOURCE_CHANNELS` | Список чатов Telegram через запятую, например: `@чат1,@чат2` — откуда читать жалобы. |
| `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` | Для доступа к Telegram (получить на my.telegram.org). |
| `KRO_SHEET_ID` | ID таблицы Google Sheets с отчётами (если используете). |

Telega.io и Telega.in скрипт проверяет **без ключей** — по публичным страницам. Для них ничего отдельно прописывать не нужно.

Если чего-то нет — добавьте и сохраните файл.

---

## Шаг 6. Запустить скрипт один раз (режим «сбор»)

1. Откройте терминал на компьютере.
2. Перейдите в папку скрипта:
   ```bash
   cd путь/к/проекту/backend/kro-worker
   ```
   (подставьте свой путь к проекту, например: `cd ~/Documents/GitHub/crypto-academy-pro/backend/kro-worker`)
3. Выполните команду:
   ```bash
   MODE=collect python3 run_12h_monitor.py
   ```
4. Подождите окончания (скрипт зайдёт на TGStat, Telega, при наличии настроек — в Telegram, затем обновит документ).
5. Если в терминале появится строка вида **«Updated sources doc: https://docs.google.com/...»** — документ обновлён.

---

## Шаг 7. Открыть документ и проверить

1. Откройте ссылку на документ (ту же, что в терминале, или из Google Диска).
2. В документе должно быть:
   - Вверху — **«SOURCE & DATA»** и описание **трёх источников** (TGStat, Telega.io/Telega.in, Telegram).
   - Блок **«ПОСЛЕДНИЙ СБОР»** с датой и временем.
   - Списки каналов по каждому источнику (если скрипт что-то нашёл).
   - Блок **«ИТОГИ ПОСЛЕДНЕГО СБОРА»** (цифры и ссылка на автоотчёт).

Если всё так — значит, скрипт уже проверяет все три сайта и записывает результат в ваш документ.

---

## Краткий чеклист

- [ ] Создан Google Doc «Источники и данные».
- [ ] Скопирован ID документа из URL.
- [ ] Сервисному аккаунту (email из `credentials.json`) выдан доступ «Редактор» к документу.
- [ ] В `env` или `.env` добавлена строка `KRO_SOURCES_DOC_ID=...` с вашим ID.
- [ ] Заданы переменные для Google, TGStat и при необходимости Telegram (см. шаг 5).
- [ ] Выполнена команда: `MODE=collect python3 run_12h_monitor.py`.
- [ ] Документ открыт и в нём есть три источника и данные последнего сбора.

---

## Если что-то не получилось

- **Документ не обновился.** Проверьте: 1) верно ли указан `KRO_SOURCES_DOC_ID`; 2) выдан ли доступ сервисному аккаунту; 3) нет ли в терминале ошибок про Google или «доступ запрещён».
- **«Нет данных за этот запуск» по одному из источников.** Для TGStat нужен рабочий `TGSTAT_API_KEY`. Для Telegram — настроенные `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и `KRO_SOURCE_CHANNELS`. Telega обычно работает без ключей.
- **Хочу запускать автоматически каждые 12 часов.** Настройте cron: в 11:00 и 23:00 MSK — `MODE=collect python3 run_12h_monitor.py`; в 12:15 и 00:15 — `MODE=publish python3 run_12h_monitor.py`. Подробнее в `backend/KRO_SETUP.md`.

После того как вы сделаете шаги 1–7, документ «Источники и данные» будет показывать и три сайта-источника, и реальные данные, которые скрипт с них собрал.
