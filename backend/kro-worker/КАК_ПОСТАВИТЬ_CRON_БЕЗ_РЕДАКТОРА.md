# Как поставить cron без редактора (по шагам)

Никакого vi и nano — только копируешь команды в терминал и жмёшь Enter.

---

## Шаг 1. Открой терминал

(В Cursor: Terminal → New Terminal, или приложение «Терминал» на Mac.)

---

## Шаг 2. Перейди в папку проекта

Скопируй целиком, вставь в терминал, нажми Enter:

```bash
cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro
```

Должна появиться строка с путём, в конце что-то вроде `crypto-academy-pro` — значит ты в нужной папке.

---

## Шаг 3. Поставь все задания разом из файла

Скопируй целиком, вставь в терминал, нажми Enter:

```bash
grep -v '^#' backend/kro-worker/CRONTAB_12h.txt | grep -v '^$' | crontab -
```

Что это делает: подставляет в cron **ровно** то, что записано в `CRONTAB_12h.txt` (все задания без комментариев). В том числе задание «каждые 5 минут» для обновления документа. Старый список заданий заменяется этим.

Ошибок быть не должно. Если команда выполнилась без сообщений — всё ок.

---

## Шаг 4. Проверь, что задания добавились

Скопируй, вставь, Enter:

```bash
crontab -l
```

Должен вывести список строк. Среди них должны быть:

- `*/5 * * * *` — это как раз «каждые 5 минут», обновление документа;
- строки с `0 11`, `0 12`, `0 23`, `15 0` (или `0 0`) — сбор и публикация 12h.

Если видишь `*/5 * * * *` — задание «каждые 5 минут» стоит.

---

## Шаг 5. (По желанию) Проверь, что скрипт вообще работает

Скопируй, вставь, Enter:

```bash
cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro/backend/kro-worker && python3 update_live_log_5min.py
```

- Если в конце что-то вроде `ok (жирным: новая строка)` или `ok (документ обновлён)` — скрипт сработал, в документе что-то должно обновиться (обнови страницу F5).
- Если пишет про «плейсхолдер не найден» — в Google-документе нужно добавить строку «События за период — ниже» (см. другие инструкции).

---

## Итого

1. `cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro`
2. `(crontab -l 2>/dev/null; grep -v '^#' backend/kro-worker/CRONTAB_12h.txt | grep -v '^$') | crontab -`
3. `crontab -l` — посмотреть список.

Редактор не нужен.
