# Что сделать, чтобы всё заработало

Цель: цифры на главной странице берутся из интернета (vklader, tgrev), обновляются скриптом, и раз в сутки обновление идёт само по расписанию.

Выполняй команды **по одной**, в том же порядке. После каждой — дождись окончания и только потом переходи к следующей.

---

## 1. Открыть терминал и перейти в папку проекта

Скопируй, вставь в терминал, нажми **Enter**:

```
cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1"
```

---

## 2. Установить зависимости Python

Скопируй, вставь, **Enter**:

```
pip3 install -r backend/kro-worker/requirements.txt
```

Если появится «command not found: pip3», вставь вместо этого и нажми **Enter**:

```
python3 -m pip install -r backend/kro-worker/requirements.txt
```

---

## 3. Один раз запустить скрипт (собрать данные из интернета)

Скопируй, вставь, **Enter**:

```
cd backend/kro-worker && python3 fetch_live_stats.py
```

В конце должно появиться сообщение вида:  
`Written: .../kro-reference-stats.json (channelsToday=..., telegramCount=..., totalLost=...)`  
Значит, данные записались.

---

## 4. Запустить бэкенд и проверить сайт

Запусти сервер так, как обычно (например из корня проекта: `npm run dev` или `node server.js`, в зависимости от проекта). Открой главную страницу в браузере.

Блок со счётчиком (новые скам‑каналы, потери, количество каналов) должен показывать цифры из `kro-reference-stats.json`. Под ними может быть подпись вроде «Данные из интернета: vklader, tgrev...».

(Если у тебя настроена Google-таблица с отчётами и там есть данные — главная может показывать их вместо JSON. Это нормально.)

---

## 5. Настроить автозапуск раз в сутки (cron)

Чтобы скрипт сам запускался каждый день в 06:00, добавь задание в crontab **одной командой** (без nano/vi).

Сначала перейди в папку проекта, если ты уже не в ней:

```
cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1"
```

Затем скопируй, вставь целиком, **Enter**:

```
(crontab -l 2>/dev/null; cat backend/kro-worker/crontab-line.txt) | crontab -
```

Проверка — вставь и **Enter**:

```
crontab -l
```

Должна быть **одна** строка:
`0 6 * * * cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1/backend/kro-worker" && python3 fetch_live_stats.py`

---

## Если в crontab две одинаковые строки

Убрать дубликат одной командой — вставь и **Enter**:

```
crontab -l | uniq | crontab -
```

Потом снова проверь: `crontab -l` — должна остаться одна строка.

---

## Кратко: что у тебя будет работать

| Что | Как |
|-----|-----|
| Данные из интернета | Скрипт `fetch_live_stats.py` качает vklader и tgrev, считает каналы и пишет в `backend/data/kro-reference-stats.json`. |
| Цифры на главной | Бэкенд отдаёт их по запросу; если таблица пуста/не настроена — берёт из этого JSON. |
| Обновление раз в сутки | Cron в 06:00 запускает тот же скрипт — файл обновляется без твоего участия. |

После шагов 1–5 всё перечисленное должно работать.
