# Как запустить сбор данных из интернета (fetch_live_stats)

Выполняй команды **по одной**, в указанном порядке.

---

## Шаг 1: Перейти в папку проекта

Скопируй и вставь в терминал (одной строкой):

```bash
cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1"
```

Нажми Enter. Дальше все команды выполняются уже из этой папки.

---

## Шаг 2: Установить зависимости

Скопируй и вставь (на macOS обычно нужен `pip3`, не `pip`):

```bash
pip3 install -r backend/kro-worker/requirements.txt
```

Если появится ошибка «pip3: command not found», попробуй:

```bash
python3 -m pip install -r backend/kro-worker/requirements.txt
```

---

## Шаг 3: Запустить скрипт один раз

```bash
cd backend/kro-worker && python3 fetch_live_stats.py
```

После этого в `backend/data/kro-reference-stats.json` появятся обновлённые данные: каналы за день, потери, число Telegram-каналов, курсы, **Топ-3** (из распарсенных каналов и сумм), **victims24h** (посты за 24ч в каналах жалоб) и подпись источника. При пустой таблице главная страница подхватит эти цифры через API live-counter.

---

## Шаг 4: Автозапуск раз в сутки (cron) — по желанию

Строку с `0 6 * * *` нужно **добавить внутрь редактора** при `crontab -e` и **обязательно сохранить**. Иначе задание не добавится.

### Вариант А: открыть cron в nano (проще)

В терминале выполни:
```bash
EDITOR=nano crontab -e
```
Откроется nano. Вставь в конец файла одну строку:
```
0 6 * * * cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1/backend/kro-worker" && python3 fetch_live_stats.py
```
Сохрани: **Ctrl+O**, Enter. Выйди: **Ctrl+X**.

### Вариант Б: если открылся vi (vim)

1. Нажми **`i`** (внизу появится `-- INSERT --`).
2. Вставь строку (Cmd+V):
   ```
   0 6 * * * cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1/backend/kro-worker" && python3 fetch_live_stats.py
   ```
3. Нажми **Esc**.
4. Введи **`:wq`** и **Enter** — сохранить и выйти.

Проверить, что задание добавилось: `crontab -l`.

---

## Переменная KRO_SOURCE_CHANNELS (опционально)

Это **не команда для терминала**. Её пишут в файл с переменными окружения.

Если у тебя в проекте есть файл `backend/kro-worker/env` или `.env` в корне — открой его в редакторе и добавь строку (подставь свои каналы):

```
KRO_SOURCE_CHANNELS=@канал1,@канал2
```

Сохрани файл. При следующем запуске `fetch_live_stats.py` скрипт будет читать и эти каналы.

## Автоотчёт каждые 12 ч (run_12h_monitor)

Скрипт `run_12h_monitor.py` работает в двух режимах: **collect** (11:00 и 23:00 MSK) — сбор из TGStat, Telega.io/telega.in, чатов Telegram, отчёт в Google Docs, запись в `kro-12h-stats-pending.json`; **publish** (12:15 и 00:15 MSK) — копирование в `backend/data/kro-12h-stats.json` для сайта. Запуск: `MODE=collect python3 run_12h_monitor.py` или `MODE=publish python3 run_12h_monitor.py`. Подробнее — `backend/KRO_SETUP.md`, раздел «Автомониторинг каждые 12 ч».
