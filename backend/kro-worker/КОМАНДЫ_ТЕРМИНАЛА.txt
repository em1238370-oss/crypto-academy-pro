═══════════════════════════════════════════════════════════════
  ВХОД В TELEGRAM ДЛЯ ПРОВЕРКИ КАНАЛОВ — КОМАНДЫ ПО ОДНОЙ
═══════════════════════════════════════════════════════════════

Открой приложение «Терминал» (Программы → Утилиты → Терминал).
Копируй команды по одной, вставляй в терминал (Cmd+V) и нажимай Enter.
Жди окончания каждой команды перед следующей.

───────────────────────────────────────────────────────────────
  КОМАНДА 1 — перейти в папку проекта
───────────────────────────────────────────────────────────────

cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1"

(Нажми Enter. Должна появиться строка с путём и процентами, без ошибки.)

───────────────────────────────────────────────────────────────
  КОМАНДА 2 — перейти в папку воркера
───────────────────────────────────────────────────────────────

cd backend/kro-worker

(Нажми Enter.)

───────────────────────────────────────────────────────────────
  КОМАНДА 3 — установить зависимости Python
───────────────────────────────────────────────────────────────

python3 -m pip install -r requirements.txt

(Нажми Enter. Подожди, пока всё установится. В конце не должно быть красных ошибок.
 Если напишет «command not found: python3» — попробуй вместо этой команды:
   python -m pip install -r requirements.txt
)

───────────────────────────────────────────────────────────────
  КОМАНДА 4 — войти в Telegram
───────────────────────────────────────────────────────────────

python3 login_telegram.py

(Нажми Enter.)

Дальше в терминале:
  1) Появится запрос: Please enter your phone (or bot token):
     Введи номер в формате +79671215577 и нажми Enter.

  2) Открой приложение Telegram на телефоне — там придёт код (5 цифр).

  3) Появится запрос: Please enter the code you received:
     Введи именно эти 5 цифр из Telegram и нажми Enter.
     (Код может прийти в приложение на телефоне или в Telegram Desktop, в т.ч. если заходила по QR-коду.)

  4) Если всё верно, появится: «Готово! Сессия сохранена. Больше ничего вводить не нужно.»

───────────────────────────────────────────────────────────────
  ПОСЛЕ УСПЕШНОГО ВХОДА
───────────────────────────────────────────────────────────────

Перезапусти бэкенд (останови его Ctrl+C в том окне, где он запущен, и запусти снова).
После этого при вставке ссылки на канал и нажатии «Проверить» результат будет приходить сразу.

═══════════════════════════════════════════════════════════════

ВАРИАНТ ОДНОЙ КОМАНДОЙ (если по шагам всё сработало):

Из корня проекта можно один раз выполнить:

  cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1"
  bash backend/kro-worker/kro-telegram-login.sh

Скрипт сам установит зависимости и запустит вход.
