# Что вставлять в терминал — по шагам

Делай **строго по порядку**: вставил строку → Enter → дождался результата → следующий шаг.

---

## Шаг 1

Скопируй эту строку целиком, вставь в терминал, нажми **Enter**:

```
cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1"
```

---

## Шаг 2

Скопируй, вставь, **Enter**:

```
pip3 install -r backend/kro-worker/requirements.txt
```

(Если напишет «command not found: pip3», тогда вставь: `python3 -m pip install -r backend/kro-worker/requirements.txt` и Enter.)

---

## Шаг 3 — запустить скрипт один раз

Скопируй, вставь, **Enter**:

```
cd backend/kro-worker && python3 fetch_live_stats.py
```

Должно появиться что-то вроде: `Written: .../kro-reference-stats.json (channelsToday=..., telegramCount=...)`. Значит, всё ок.

---

## Шаг 4 — автозапуск раз в сутки (по желанию)

**4.1.** Скопируй, вставь в терминал, **Enter**:

```
EDITOR=nano crontab -e
```

Откроется окно редактора (nano).

**4.2.** В окне nano удали всё, что там есть (если осталась обрезанная строка). Скопируй и вставь **целиком** одну строку — от начала до конца, без символа `$` и без обрезки (должно быть `backend/kro-worker` и в конце `&& python3 fetch_live_stats.py`):

```
0 6 * * * cd "/Users/macmini/Documents/Crypto academy pro/crypto-academy-pro1/backend/kro-worker" && python3 fetch_live_stats.py
```

**4.3.** Сохрани файл: нажми **Ctrl+O**, потом **Enter**.

**4.4.** Выйди из редактора: нажми **Ctrl+X**.

Готово. Скрипт будет запускаться каждый день в 06:00.

---

## Проверка (опционально)

Чтобы увидеть, что задание в cron добавилось, вставь в терминал и нажми **Enter**:

```
crontab -l
```

Должна показаться строка с `0 6 * * *` и путём к `fetch_live_stats.py`.
