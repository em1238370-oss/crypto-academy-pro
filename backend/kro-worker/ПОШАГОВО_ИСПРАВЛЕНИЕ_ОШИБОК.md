# Пошаговое исправление ошибок — KRO Sources & Data

Делай шаги по порядку. Если на каком-то шаге ошибка — остановись и исправь по подсказке, потом иди дальше.

---

## Шаг 1. Проверь, что ты в нужной папке

В терминале выполни:

```bash
cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro/backend/kro-worker
pwd
```

Должно вывести путь, который заканчивается на `.../crypto-academy-pro/backend/kro-worker`.  
Если нет — скопируй путь из вывода и снова выполни `cd` с этим путём.

## Шаг 2. Проверь, что есть .env с настройками

В той же папке выполни:

```bash
ls -la .env
```

- Если файл есть — переходи к шагу 3.
- Если «No such file» — создай файл `.env` в папке `kro-worker` и запиши в него хотя бы:
  - `KRO_SOURCES_DOC_ID=1VA3Vrt6sak_TXypqBqQalOWe0JHdQm20gz80s6rfi58` (ID твоего документа)
  - И при необходимости `KRO_GOOGLE_CREDENTIALS_JSON=...` или путь к `credentials.json` (как у тебя уже настроено для Google).

Сохрани файл и снова выполни шаг 2, чтобы убедиться, что файл на месте.

---

## Шаг 3. Запусти основной скрипт (обновление документа)

В терминале (всё ещё в папке `kro-worker`):

```bash
python3 run_12h_monitor.py
```

Смотри вывод:

- **«Готово. Документ «Источники и данные» обновлён: https://...»** — всё ок. Открой ссылку и обнови страницу (F5): в документе должна быть новая структура и время курсивом.
- **«Sources doc: курсив применён к N фрагментам времени»** — курсив для времени сработал.
- **«Создание нового отчёта пропущено: 403»** — это нормально, документ «Источники и данные» обновляется отдельно.
- **«Не удалось обновить документ»** или ошибка про credentials — переходи к шагу 4.
- Ошибка про `tgstat_client` или сеть — скрипт всё равно может обновить документ; если в конце есть «Готово. Документ...», шаг 3 выполнен.

Если документ обновился — переходи к шагу 5. Если нет — шаг 4.

## Шаг 4. Если документ не обновляется (ошибка Google)

Проверь:

1. **Учётные данные**
   - В папке `kro-worker` есть файл `credentials.json` (или `kro-google-credentials.json`), **или**
   - В `.env` задан `KRO_GOOGLE_CREDENTIALS_JSON` (целиком JSON ключа сервисного аккаунта).

2. **Доступ к документу**
   - Открой документ «Sources and Data» в браузере.
   - Поделиться → добавь **email из ключа** (поле `client_email` в JSON) с правом **Редактор**.

3. **Повторный запуск**
   Снова выполни в `kro-worker`:
   ```bash
   python3 run_12h_monitor.py
   ```
   Если снова ошибка — пришли текст ошибки из терминала.

## Шаг 5. Запусти скрипт «каждые 5 минут» один раз вручную

В терминале (в папке `kro-worker`):

```bash
python3 update_live_log_5min.py
```

Не вводи строку с `*/5 * * * *` — только эту команду.

Смотри вывод:

- **«HH:MM ok (жирным: новая строка): ...»** — скрипт сработал, в документе под «Обновления каждые 5 мин» должна появиться строка (и она будет жирной).
- **«KRO_SOURCES_DOC_ID не задан»** — в `.env` добавь `KRO_SOURCES_DOC_ID=...` (как в шаге 2) и запусти снова.
- Другая ошибка — пришли текст из терминала.

Открой документ и обнови страницу: под «Обновления каждые 5 мин» должна быть хотя бы одна строка с временем.

## Шаг 6. Настроить автоматический запуск каждые 5 минут (cron)

Эту команду **не вводи в терминал как одну строку** — она для расписания.

1. Открой список своих cron-задач:
   ```bash
   crontab -e
   ```

2. Если спросят «выбери редактор» — выбери nano (обычно цифра 1 или просто Enter).

3. В конец открывшегося файла добавь **одну строку** (скопируй целиком, путь уже подставлен):
   ```
   */5 * * * * cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro/backend/kro-worker && python3 update_live_log_5min.py
   ```

4. Сохрани и выйди:
   - в nano: `Ctrl+O`, Enter, потом `Ctrl+X`.

5. Проверь, что задача добавилась:
   ```bash
   crontab -l
   ```
   Должна быть строка с `*/5` и `update_live_log_5min.py`.

После этого каждые 5 минут скрипт будет сам дописывать строку в документ и выделять её жирным.

## Краткая шпаргалка команд (без cron)

Все команды выполняются из папки `kro-worker` (сначала `cd .../kro-worker`).

| Что сделать | Команда |
|-------------|--------|
| Обновить документ Sources & Data (разово) | `python3 run_12h_monitor.py` |
| Добавить одну строку в «Обновления каждые 5 мин» (разово) | `python3 update_live_log_5min.py` |
| Открыть настройку cron | `crontab -e` |
| Посмотреть текущие cron-задачи | `crontab -l` |

**Не вводи в терминал:** `*/5 * * * * ...` — это только для вставки внутрь файла при `crontab -e`.
