# Код от Telegram не приходит (вход для воркера)

Telegram иногда не присылает или сильно задерживает код для входа через API (Telethon). Что можно сделать:

---

## 1. Формат номера

Вводи номер **строго в международном формате**, без пробелов и скобок:
- Правильно: `+79001234567`
- Неправильно: `89001234567`, `8 900 123 45 67`, `+7 (900) 123-45-67`

Попробуй ещё раз с форматом `+79...`.

---

## 2. Подождать и повторить

Останови скрипт (**Ctrl+C**), подожди **30–60 минут** и запусти снова:

```bash
python3 run_with_env.py @durov
```

Иногда после паузы код приходит с первой попытки.

---

## 3. Отдельный аккаунт для воркера

Самый надёжный вариант — завести **второй номер** (другой SIM или виртуальный номер) и создать отдельный аккаунт Telegram только для проверки каналов. Тогда:
- основной аккаунт не трогаешь;
- для воркера логинишься один раз с этого номера — код для новых/редких входов часто приходит быстрее.

Сессию потом храни в `kro_worker.session` и больше не вводишь код.

---

## 4. Пока воркер не залогинен — как жить без него

Пока нет сессии Telethon:
- **Сайт работает**: проверка по базе (scam_base), форма жалоб.
- **Живая проверка по Telegram** (канал не в базе → добавить в очередь → воркер проверяет) будет доступна только после успешного входа один раз.

Можно заполнять scam_base вручную (добавлять каналы в таблицу) или подождать, пока код придёт / пока сделаешь отдельный аккаунт для воркера.

---

## 5. Если включена двухфакторная авторизация (2FA)

Если в аккаунте включён пароль облачной пароль (2FA), после кода из приложения скрипт спросит ещё и этот пароль. Код из чата «Telegram» всё равно нужен первым.
