# Вход по QR-коду — без кода в приложении

Вместо кода из Telegram можно войти по **QR-коду**: открываешь Telegram на телефоне, сканируешь QR — сессия создаётся без ввода кода.

---

## Что нужно

- Файл **env** с **TELEGRAM_API_ID** и **TELEGRAM_API_HASH** (твои с my.telegram.org, не 2040).
- Telegram на телефоне с уже залогиненным аккаунтом.

---

## Шаги

### 1. Установи библиотеку для QR (один раз)

```bash
cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro/backend/kro-worker
source venv/bin/activate
pip install "qrcode[pil]"
```

### 2. Запусти вход по QR

```bash
set -a && source env && set +a
python3 login_via_qr.py
```

### 3. Что будет

- Откроется **окно с QR-кодом** (или в терминале появится ссылка, если окно не открылось).
- На **телефоне** открой Telegram → **Настройки** → **Устройства** → **Подключить устройство** (или **Link Desktop Device**).
- **Отсканируй QR** камерой через интерфейс Telegram.
- В терминале появится «Вход выполнен» — сессия сохранена в `kro_worker.session`.

### 4. Если включён пароль 2FA

Терминал просит **облачный пароль** — это **не** пароль от телефона и **не** код из SMS.  
Если скрипт дошёл до запроса пароля, значит на аккаунте **уже когда‑то** включали двухэтапную проверку (даже если сейчас в меню не ищется).

**Где искать в приложении (названия от версии к версии отличаются):**

| Клиент | Куда зайти |
|--------|------------|
| **Telegram на телефоне (iOS/Android)** | **Настройки** (шестерёнка) → **Конфиденциальность** *или* **Конфиденциальность и безопасность** → прокрутить список **вниз** → пункт вроде **«Двухэтапная аутентификация»**, **«Облачный пароль»**, **Two-Step Verification** |
| **Telegram Desktop (Mac/Windows)** | **Настройки** → **Конфиденциальность** → **Двухэтапная аутентификация** |

Если в **Конфиденциальности** только «кто видит номер / фото» — откройте **главные Настройки** именно **основного** меню (не настройки отдельного канала). В строке поиска по настройкам иногда можно набрать **«пароль»** или **«two»**.

**Если пункта нет, а пароль всё равно спрашивают:** воспользуйтесь **«Забыли пароль?»** в том же экране входа на новое устройство в Telegram (или инструкциями восстановления по e-mail, если вы его привязывали при включении 2FA).

В терминале введите **тот** пароль, который задавался при включении этой защиты.

```bash
python3 run_with_env.py @durov

```

Код вводить больше не нужно — используется созданная сессия.

---

## Важно

- В **env** / **.env** укажи **свои** TELEGRAM_API_ID и TELEGRAM_API_HASH с my.telegram.org, не подменяй на чужие примеры (в старых инструкциях встречался тестовый 2040).
- QR действует примерно 30 секунд. Если не успела — запусти `python3 login_via_qr.py` ещё раз и отсканируй новый QR.
