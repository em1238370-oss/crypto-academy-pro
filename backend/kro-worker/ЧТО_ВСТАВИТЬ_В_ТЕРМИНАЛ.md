# Что вставить в терминал, чтобы каждые 5 минут появлялся жирный текст

**Почему в документе нет изменений:** чтобы в [Sources and Data](https://docs.google.com/document/d/1VA3Vrt6sak_TXypqBqQalOWeOJHdQm20gz80s6rfi58/edit) что-то обновлялось каждые 5 минут, нужно: (1) в документе должна быть строка **«События за период — ниже»** — если её нет, нельзя перезаписывать весь документ обычным текстом, потому что это удаляет нативные таблицы Google Docs; для восстановления живого блока используйте `python3 fix_sources_doc_block_once.py` или вставьте только блок из `backend/data/sources_doc_block_to_paste.txt`; (2) скрипт должен реально запускаться каждые 5 мин (cron или цикл ниже); (3) в папке `kro-worker` нужны учётные данные Google (файл `credentials.json` или переменная `KRO_GOOGLE_CREDENTIALS_JSON` в `.env`), и документ должен быть доступен сервисному аккаунту (Поделиться → добавить email из ключа).

В документе Sources and Data есть блок **«Обновления каждые 5 мин»** и плейсхолдер «События за период — ниже». Скрипт каждые 5 минут **подтягивает данные** (TGStat, Telega, жалобы) и дописывает строку в документ.

Скопируй и вставь команды **по очереди** (после каждой нажимай Enter).

---

## Сначала: один раз проверить, что жирная строка появляется

Вставь в терминал **эти две строки** (по одной):

```bash
cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro/backend/kro-worker
python3 update_live_log_5min.py
```

Должно появиться что-то вроде: `14:35 ok (жирным: новая строка): ...`  
Открой документ Sources and Data и обнови страницу — под «Обновления каждые 5 мин» должна быть одна строка **жирным**. Если так и есть, переходи к способу 1 или 2 ниже.

---

## Способ 1. Цикл в терминале (без cron)

Один раз запускаешь — скрипт сам каждые 5 минут добавляет строку. Терминал не закрывай.

**Вставь в терминал:**

```bash
cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro/backend/kro-worker
bash run_live_log_loop.sh
```

Оставь это окно терминала открытым. Каждые 5 минут будет появляться новая жирная строка в документе.

**Чтобы запустить в фоне** (терминал можно закрыть, цикл продолжит работать):

```bash
cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro/backend/kro-worker
nohup bash run_live_log_loop.sh > live_log_loop.log 2>&1 &
```

После этой команды **терминал «замолкает» и ничего не пишет** — это нормально. Скрипт работает в фоне, весь вывод идёт в файл `live_log_loop.log`, а не в окно терминала. Каждые 5 минут в документе появляется новая жирная строка; в терминале новых строк не будет.

**Как убедиться, что всё работает:** открой документ Sources and Data и обновляй страницу (F5) раз в 5 минут — под «Обновления каждые 5 мин» должны подрастать строки, последняя жирным. Или посмотри лог: в терминале выполни `tail -20 live_log_loop.log` (из папки kro-worker) — там будут строки вида `19:25 ok (жирным: новая строка): ...`.

Остановить цикл: найди процесс (`ps aux | grep run_live_log_loop`) и заверши его (`kill <номер>`).

## Способ 2. Через cron (каждые 5 минут по расписанию)

**Шаг 1.** Открой редактор cron одной командой:

```bash
crontab -e
```

**Шаг 2.** Если спросят «Choose editor» — введи `1` и Enter (nano).

**Шаг 3.** В открывшемся файле в **конец** (после последней строки) вставь ровно эту одну строку:

```
*/5 * * * * cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro/backend/kro-worker && python3 update_live_log_5min.py
```

**Шаг 4.** Сохрани и выйди:
- в nano: нажми `Ctrl+O`, затем Enter, затем `Ctrl+X`.

Готово. Теперь система сама каждые 5 минут будет запускать скрипт.

## Если не сработало

- **В документе нет строки «События за период — ниже»** — не вставляйте в рабочий документ весь файл `Sources-and-Data-ВСТАВИТЬ-В-GOOGLE-DOC.txt`: это удалит нативные таблицы. Вместо этого запустите `python3 fix_sources_doc_block_once.py` или вставьте только блок из `backend/data/sources_doc_block_to_paste.txt`.
- Убедись, что в папке `kro-worker` есть учётные данные Google (`credentials.json` или `KRO_GOOGLE_CREDENTIALS_JSON` в `.env`) и что документ **расшарен** на email сервисного аккаунта (Поделиться → добавить).
- Проверь, что один раз команда `python3 update_live_log_5min.py` выполняется без ошибки (см. блок «Сначала» выше). Если в терминале «в документе не найден плейсхолдер» — добавь эту строку в документ.
- Чтобы обновления шли автоматически каждые 5 мин, нужен либо cron (см. CRONTAB_12h.txt — там есть строка `*/5 * * * *`), либо запущенный цикл `bash run_live_log_loop.sh`.
