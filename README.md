# Check your crypto

## 🌐 Сайт
**URL:** https://crypto-academy-pro.onrender.com/

## 📋 О проекте

**Check your crypto** («Крипта без розовых очков») — сервис про безопасность в крипте: проверка каналов и гуру на скам, чекер каналов, форма «Сообщить о разводе», живая статистика.

- Главная: лендинг, Hero, блок с LIVE-цифрами, проверка канала, топ скам-каналов, форма жалоб.
- Подсайты: News, Risk (распределение рисков), курс основ, советник — доступ по ссылкам из шапки.
