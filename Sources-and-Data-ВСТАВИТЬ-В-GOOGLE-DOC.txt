1. Структура документа по дню
• Один лог‑блок на день: «Период: DD.MM.YYYY 00:00 – DD.MM.YYYY 23:55 (MSK)», «Время формирования: DD месяц, 23:55 MSK».
• Раздел «Временная линия дня:» и строки событий.
• Время по возрастанию 00:00–23:55; каждая HH:MM не больше одного раза; запрет дублирования блоков.
• Списки каналов не в логе — только в таблице.

2. Формат временной линии
Формат: HH:MM — краткое описание (одна строка).
Пример: 00:00 — Начат сбор данных. 00:05 — TGStat/Telega: найдено каналов — TGStat 0, Telega 0. … 23:55 — Завершён сбор данных.
Правила: только «когда» и «что в общем»; никаких списков @каналов и «(3/6 рисков)» в логах.

3. Главная таблица «Объекты и риск»
Одна таблица на день. 8 столбцов. 1‑я строка — заголовки (жирным).

3.2. Что именно писать в КАЖДУЮ ячейку строки
Каждая строка = один объект (канал / бот / сайт).

Столбец 1 — Объект / ссылка
• Канал: текст @username и гиперссылка https://t.me/username.
• Сайт/курс: текст example.com и ссылка https://example.com.
• Если ссылка не открывается или не про крипту/сигналы — строку не создавать.

Столбец 2 — Тип
Одно значение: сигнал‑канал, крипто‑канал (новости), бот, сайт/курс, обучение. Без описаний.

Столбец 3 — Источник
каталог Telegram, поиск в Telegram, чат с жалобами, поиск в интернете. До двух через «+».

Столбец 4 — Краткое описание
1–2 предложения по факту. Примеры: «Канал даёт торговые сигналы по криптовалютам и обещает высокий процент успешных сделок.» «Публикует новости без продажи сигналов или VIP.» Только то, что видно. Без оценок «мошенники», «плохой».

Столбец 5 — VIP / деньги
Примеры: «VIP‑подписка 15 000₽ / месяц»; «Закрытый VIP, цена не указана, просит в личку»; «Платных услуг не обнаружено.» Только реальные данные.

Столбец 6 — Жалобы / отзывы
Примеры: «2 человека в чате X пишут, что после сигналов слили депозит (без суммы).» «Жалоб за период не найдено.» Если сумм нет — не придумывать.

Столбец 7 — Признаки риска (флаги)
Конкретные флаги по факту. Структура/поведение: «новый канал (< 14 дней)», «дорогой VIP (от ~10 000₽)», «обещания x2/x5, без риска, гарантированный доход», «много картинок монет со стрелками», «объяснения короткие, без сценариев риска», «активно продаёт VIP (пиши в ЛС, осталось мало мест)», «показывает только прибыльные сделки». VWAP (если используется): «лонги ниже VWAP», «шорты выше VWAP», «сигналы далеко от VWAP (>2–3%)». Через запятую или с новой строки. Ни одного флага нельзя придумать.

Столбец 8 — Итоговый статус
Резюме по 4–7: «в риске (структура + поведение + жалобы)», «поведенческий риск (жалоб нет)», «жалобы, но мало данных по контенту», «без риска (новости/аналитика)», «под наблюдением (мало данных)». Только из предыдущих столбцов.

4. Приоритет: сигнальные каналы
• Главный приоритет — сигнал‑каналы по крипте.
• Новости/аналитика без продажи сигналов — не рисковые, пометить «без риска (новости/аналитика)».
• Для каждого сигнального канала в таблице обязательно: ссылка; что делает; как продаёт VIP/курсы; флаги; жалобы; итоговый статус.

5. Связь документа с сайтом
• Цифры на сайте прослеживаемы до таблицы «Объекты и риск» и таблиц сигналов/VWAP.
• В конце блока за день: сколько строк «в риске»; сумма потерь; какие объекты в топ‑3 (по жалобам/флагам/потерям).
• Никаких чисел «из воздуха».

6. Жёсткие запреты (для Cursor)
• Запрещено дублировать блок логов (одно время и те же каналы) внутри дня.
• Запрещено выводить списки @каналов в логах по времени — только в таблице.
• Запрещено придумывать каналы, суммы, жалобы, флаги.
• Разрешено «жалоб нет», «платных услуг не обнаружено», «мало данных»; нельзя «рисовать картинку для красоты».
• Ссылка не открывается — объект не в таблицу.
