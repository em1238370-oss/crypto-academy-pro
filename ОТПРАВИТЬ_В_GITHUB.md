# Как отправить изменения в GitHub (чтобы сайт обновился)

## Почему кнопка не показывает обновление

Часто GitHub Desktop открыт на **другой папке** (например `Documents/Crypto academy pro/crypto-academy-pro1`).  
Все правки сделаны в папке **crypto-website** — поэтому в той другой папке «нет изменений» и нечего пушить.

---

## Что сделать по шагам

### 1. Открой нужную папку в GitHub Desktop

1. Запусти **GitHub Desktop**.
2. Меню **File → Add Local Repository…** (или **Repository → Add…**).
3. Укажи **именно эту папку**:
   ```
   /Users/macmini/crypto-website
   ```
   Можно нажать **Choose…** и найти папку `crypto-website` на диске (часто в домашней папке macmini).
4. Нажми **Add Repository**.

### 2. Проверь, что репозиторий тот самый

- Вверху должно быть: **crypto-academy-pro** (или имя твоего репозитория).
- В списке изменений или в истории коммитов должен быть коммит:  
  **«Risk DNA: scenario as bold text + circular arrow buttons…»**

### 3. Отправь изменения на GitHub

- Если слева написано **«Push origin»** или есть коммиты для отправки — нажми **Push origin**.
- Если написано **«No local changes»** / «Nothing to commit» — проверь вкладку **History**: если там уже есть коммит «Risk DNA: scenario as bold text…», значит, он уже отправлен (или GitHub Desktop считает, что так). Тогда нажми **Repository → Push** (или кнопку **Push** вверху).

### 4. После успешного Push

- На Render сайт обновится сам (если включён автодеплой из GitHub).
- Обновление может занять 1–3 минуты.

---

**Важно:** работай с папкой **crypto-website**, а не с копией проекта в Documents — иначе кнопка «обновление» не появится, потому что изменений в той копии нет.
