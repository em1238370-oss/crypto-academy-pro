## ГЛАВНЫЙ ПРИНЦИП ПРОДУКТА (не менять никогда)

**Люди платят не за данные. Они платят за решение и за то чтобы не чувствовать себя идиотами.**

Продукт — это не аналитический отчёт. Это умный друг который уже посмотрел канал и говорит прямо: что нашёл, что скрыто, что делать.

### Роль продукта — «путник»
Человек потерял деньги или боится потерять. Он чувствует:
- Стыд — «я был наивным». Не хочет это признавать.
- Желание доказательств — «этот канал меня обманул, докажи».
- Растерянность — «как отличить нормальный от скама?»
- Готовность платить — «скажи правду, я заплачу чтобы не ошибиться снова».

Продукт должен: валидировать его чувство, раскрыть то что он не видел, дать конкретное действие.

### Тон — не юрист, не аналитик. Друг.
❌ «Система обнаружила признаки монетизации через реферальные программы»
✅ «Их настоящий заработок — твой переход в Bybit. Ты продукт, не клиент.»

❌ «Риск 6/10. Есть и полезное, и резкие формулировки»
✅ «Смотри бесплатно. VIP не нужен — на YouTube то же самое.»

## КАК ДОЛЖЕН ВЫГЛЯДЕТЬ РЕЗУЛЬТАТ

### Главный экран (5 секунд — всё ясно)
1. Бейдж: 🔴 опасный / 🟡 осторожно / 🟢 можно
2. **ВЕРДИКТ** — первое слово = решение: «Не плати», «Уйди», «Смотри бесплатно», «Опасно»
3. **РАСКРЫТИЕ** (reveal_moment) — то что не видно снаружи. Одна фраза. «Ты продукт, не клиент»
4. **ЧТО ДЕЛАТЬ** (next_action) — конкретное действие. «Посмотри их YouTube бесплатно», «Уйди немедленно»
5. Максимум 3 буллета с доказательствами

### Всё остальное — под кнопкой «Подробнее»


```
заработать                                       на канал + автора        с пониманием
```

**Ключевой момент:** Tool 1 встречает человека в точке 02 — между интересом и решением.
Это самый дорогой момент психологически. Люди платят чтобы снять тревогу.

- Верит что можно найти «правильный» канал

**Оба типа = один человек в разные моменты жизни.**
Боль реальная, деньги есть, решение нужно прямо сейчас.

## Текущие проблемы (решаем по приоритету)

### 🚨 Критично — решить первым:

**1. Анонимные каналы дают пустой результат**
- Проблема: большинство скамеров анонимны, AI говорит «Аноним, не упоминается»
- Человек заплатил $14 и получил ничего → убивает продукт
- Решение: веб-поиск по нику/имени (см. ниже)

**2. Нет поиска по интернету**
- Сейчас: анализируем только то что написано в описании канала
- Нужно: искать ник/имя в Google, Reddit, базах жалоб
- Решение: Brave Search API (2000 бесплатных запросов/мес)

**3. Скорость — 2-3 минуты слишком долго**
- Люди уходят если ждать дольше 30 секунд
- Решение: быстрый базовый результат за 15-30 сек + детали догружаются

### ⚠️ Важно — решить вторым:

**4. «Красный флаг» для анонимов**
- Если автор скрывает личность — это САМО ПО СЕБЕ красный флаг
- Добавить текст: «Автор скрывает личность. Если продукт действительно ценный — почему анонимно?»
- Это честно и полезно даже когда данных нет

**5. Нет проверки точности сигналов**
- Ключевой вопрос пользователя: «А их сигналы вообще работают?»
- Нужно: брать прошлые сигналы канала и сверять с реальными ценами
- Технически сложно, но это killer feature для $14

**6. Нет накопления базы**
- Каждая проверка с нуля
- Нужно: сохранять результаты, строить базу проверенных каналов
- Со временем Tool 1 становится сильнее автоматически

## СПИСОК МАНИПУЛЯТИВНЫХ СХЕМ

Mistral проверяет каждый пост канала против этого списка. Найденная схема → в `red_flags` с цитатой.

**СХЕМЫ РОСТА АУДИТОРИИ (подозрительные):**
- «Реферальная ловушка»: бесплатный доступ только если приведёшь друга/зарегистрируешься по ссылке
- «Сеть каналов»: продвигает свои же другие каналы, создаёт иллюзию независимых источников
- «Социальное доказательство»: «уже 5000 учеников», «300 человек в VIP» без проверяемых данных
- «Закрытый клуб»: намекает что бесплатная часть — только витрина, настоящее только за деньги

**СХЕМЫ МАНИПУЛЯЦИИ ДОВЕРИЕМ:**
- «Ложный авторитет»: заявляет опыт/образование без доказательств («10 лет в трейдинге»)
- «Только плюсы»: публикует скрины прибыли, убытки не показывает или упоминает вскользь
- «Личное участие»: «я сам вошёл», «вместе с вами» — создаёт ощущение что рискует своими деньгами
- «Неверифицируемые результаты»: скрины без даты, без счёта, без объяснения риска

**СХЕМЫ ДАВЛЕНИЯ:**
- «FOMO»: срочность, «последний шанс», «завтра поздно», «все уже в деле»
- «Стадный эффект»: «остальные уже зарабатывают, только ты нет»
- «Зависимость»: «без меня потеряешь», «только я понимаю этот рынок»
- «Воронка продаж»: бесплатный контент → платный VIP → дорогой курс → личный коучинг

**Формат ответа в red_flags:** `«[Название схемы]: цитата из поста»` или `Явных манипулятивных схем не найдено`.

**Тон ответа (главный принцип):** умный друг, который уже посмотрел канал. Прямо, без отмазок. Задача — дать решение, не отчёт. Поля `verdict`, `reveal_moment`, `next_action` — для этого.
