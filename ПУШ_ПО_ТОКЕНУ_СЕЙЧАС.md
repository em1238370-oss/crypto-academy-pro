# Как отправить всё в GitHub прямо сейчас (по токену)

Пуш не проходит, потому что используется **SSH**, а ключ не настроен. Ниже — переключение на **HTTPS** и вход по **токену**. Сделай это в **Терминале** (не в GitHub Desktop).

---

## Шаг 1. Переключить репозиторий на HTTPS

Открой **Терминал** и выполни (скопируй целиком):

```bash
cd /Users/elizavetamedvedeva/Documents/GitHub/crypto-academy-pro
git remote set-url origin https://github.com/em1238370-oss/crypto-academy-pro.git
```

Проверь:

```bash
git remote -v
```

Должно быть: `origin  https://github.com/em1238370-oss/crypto-academy-pro.git`

---

## Шаг 2. Создать токен на GitHub

1. Открой в браузере: **https://github.com/settings/tokens**
2. Нажми **«Generate new token»** → **«Generate new token (classic)»**
3. **Note:** например `push crypto-academy-pro`
4. **Expiration:** 90 days или No expiration
5. Поставь галочку **repo** (полный доступ к репозиториям)
6. Внизу нажми **«Generate token»**
7. **Скопируй токен** (он показывается один раз) и сохрани в надёжное место

---

## Шаг 3. Запушить

В Терминале (в той же папке проекта):

```bash
git push origin main
```

Когда спросит:
- **Username:** введи `em1238370-oss`
- **Password:** вставь **токен** (не пароль от аккаунта GitHub)

После этого push должен пройти, и все коммиты (KRO + документация) окажутся на GitHub.

---

## Шаг 4. Чтобы пароль не спрашивали каждый раз (по желанию)

```bash
git config --global credential.helper osxkeychain
```

При следующем push macOS сохранит логин и токен в «Связка ключей».

---

## Если в GitHub Desktop потом тоже хочешь пушить

После того как в Терминале один раз успешно выполнишь `git push`, в GitHub Desktop выбери **Repository → Push** — часто после успешного HTTPS-пуша из терминала Desktop тоже начинает пушить без ошибки (учётные данные общие). Если снова «Authentication failed» — в настройках Desktop выйди из аккаунта и войди заново; при запросе пароля вставь тот же **токен**.
