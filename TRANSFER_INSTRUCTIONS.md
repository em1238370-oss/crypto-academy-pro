# 📦 Инструкции по переносу проекта на другой компьютер

## ✅ Шаг 1: Проект уже сохранен на GitHub

Все изменения закоммичены и запушены на GitHub:
- **Репозиторий:** https://github.com/em1238370-oss/crypto-academy-pro.git
- **Размер проекта:** ~30 MB

---

## 🚀 Шаг 2: На новом компьютере

### Вариант A: Через GitHub (Рекомендуется)

1. **Установите Git** (если еще не установлен):
   ```bash
   # На Mac:
   # Git обычно уже установлен, проверьте:
   git --version
   
   # Если нет, установите через Homebrew:
   brew install git
   ```

2. **Клонируйте репозиторий:**
   ```bash
   cd ~/Desktop  # или любая другая папка
   git clone https://github.com/em1238370-oss/crypto-academy-pro.git
   cd crypto-academy-pro
   ```

3. **Установите зависимости:**
   ```bash
   npm install
   ```

4. **Создайте файл `.env`:**
   ```bash
   # Скопируйте все переменные из старого .env файла
   # Или создайте новый с теми же ключами
   ```

5. **Запустите проект:**
   ```bash
   npm start
   # или для разработки:
   npm run dev
   ```

---

### Вариант B: Через USB/Внешний диск

1. **Скопируйте всю папку `crypto-website`** на USB/внешний диск

2. **На новом компьютере:**
   - Вставьте USB/подключите диск
   - Скопируйте папку `crypto-website` в нужное место
   - Откройте терминал в этой папке
   - Выполните: `npm install`
   - Создайте `.env` файл с ключами
   - Запустите: `npm start`

---

## ⚙️ Шаг 3: Настройка окружения

### Создайте файл `.env` в корне проекта:

```env
# API Keys
MISTRAL_API_KEY=your_mistral_key_here
LIVECOINWATCH_API_KEY=your_livecoinwatch_key_here

# Payment Providers
NOWPAYMENTS_API_KEY=your_nowpayments_key_here
NOWPAYMENTS_IPN_SECRET=your_ipn_secret_here

# Server
PORT=4000
NODE_ENV=production
```

**⚠️ ВАЖНО:** Не забудьте скопировать все ключи из старого `.env` файла!

---

## 📋 Шаг 4: Проверка

После клонирования/копирования проверьте:

1. **Все файлы на месте:**
   ```bash
   ls -la
   # Должны быть: package.json, backend/, sub-sites/, и т.д.
   ```

2. **Зависимости установлены:**
   ```bash
   npm list --depth=0
   ```

3. **Проект запускается:**
   ```bash
   npm start
   # Должен запуститься на http://localhost:4000
   ```

## 🆘 Если что-то не работает:

1. **Проверьте версию Node.js:**
   ```bash
   node --version
   # Должна быть 14+ или 16+
   ```

2. **Переустановите зависимости:**
   ```bash
   rm -rf node_modules package-lock.json
   npm install
   ```

3. **Проверьте `.env` файл:**
   - Все ключи должны быть заполнены
   - Нет лишних пробелов
   - Правильный формат

---

## 📞 Контакты для помощи:

Если возникнут проблемы при переносе, проверьте:

- Установлены ли зависимости (`npm install`)
- Правильно ли настроен `.env` файл
- Запущен ли сервер (`npm start`)
