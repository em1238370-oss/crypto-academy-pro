# Как отправить обновления на GitHub (и на сайт Render)

Путь к репозиторию — НЕ «/путь/к/вашему/», а реальная папка на вашем Mac.

## Команды (скопируйте и вставьте в Терминал по одной):

cd ~/Documents/GitHub/crypto-academy-pro

git push origin main

---

После успешного push:
1. Render сам подхватит изменения с GitHub (если настроен автодеплой).
2. Через 2–5 минут откройте https://crypto-academy-pro.onrender.com/
3. Сделайте жёсткое обновление страницы: Cmd+Shift+R (чтобы не подхватился старый кэш CSS).

Коммит уже сделан: «Hero: шрифт Syne, градиент заголовка, стекло, тени и анимации».
