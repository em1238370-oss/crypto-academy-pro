# 📋 Скопируй и обнови — 3 минуты

## Шаг 1. Скопировать 3 файла в Finder

1. **Открой Finder** (двойной клик на иконку Finder)
2. Перейди в папку **ИСТОЧНИК** (откуда копировать):
   ```
   Documents → Crypto academy pro → crypto-academy-pro1 → sub-sites → crypto-coach
   ```
3. Выдели и скопируй (Cmd+C) эти 2 файла:
   - **index.html**
   - **styles.css**
4. Открой папку **scripts** (внутри crypto-coach)
5. Скопируй (Cmd+C) файл **table-modules.js**

---

## Шаг 2. Вставить в crypto-website

1. В Finder нажми **Cmd+Shift+G** (Перейти к папке)
2. Вставь путь: `/Users/macmini/crypto-website/sub-sites/crypto-coach`
3. Нажми **Перейти**
4. Вставь (Cmd+V) **index.html** и **styles.css** — выбери **Заменить**
5. Открой папку **scripts**
6. Вставь (Cmd+V) **table-modules.js** — выбери **Заменить**

---

## Шаг 3. GitHub Desktop — как раньше

1. Открой **GitHub Desktop**
2. Убедись, что выбран репозиторий **crypto-academy-pro** (папка crypto-website)
3. Слева увидишь **Changes (3)** — 3 изменённых файла
4. Внизу в поле **Summary** напиши: `Assignment 3, 4 - Crypto Coach`
5. Нажми синюю кнопку **Commit to main**
6. Нажми **Push origin**

Готово. Сайт обновится через 1–2 минуты.
