## Что за проект

Сайт «Крипта без розовых очков» — https://crypto-academy-pro.onrender.com/
Набор инструментов для проверки крипто-каналов в Telegram.

Стек: Node.js (Express), задеплоен на Render, данные частично в Google Sheets.
Главный бэкенд: `backend/server.js` (~12 600 строк).
Главная страница: `index.html`.
Страница отчёта по каналу: `channel.html`.

Рабочий процесс: **Я (AI) редактирую файлы → пользователь пушит в GitHub → Render деплоит автоматически.**

## Инструмент 1 — «Кто за каналом»

Пользователь вводит @username → получает досье на автора канала.

### Что делает сейчас:
- Читает посты канала через публичный t.me/s
- Извлекает соцсети из описания
- DuckDuckGo Instant API — бесплатный поиск по нику
- **Каскадный веб-поиск** (добавлен 2026-06-15): Tavily → Google CSE → Serper
- Mistral AI (`mistral-medium-latest`) анализирует и выдаёт JSON
- Анонимный канал → автоматический ответ «Опасно — автор намеренно скрывает личность»

### Ключевые функции в backend/server.js:
| Функция | Строка | Что делает |
|---|---|---|
| `kroTavilySearch` | ~5170 | Tavily API поиск (1000/мес бесплатно) — НОВАЯ |
| `kroGoogleCseSearch` | ~5185 | Google CSE поиск (3000/мес бесплатно) — НОВАЯ |
| `kroUnifiedWebSearch` | ~5205 | Каскад: Tavily → Google CSE → Serper — НОВАЯ |
| `kroAnalyzePersonBehind` | ~5350 | Главная функция AI-анализа автора |
| `kroFetchPersonBehindWebContext` | ~5235 | Веб-поиск перед Mistral (теперь работает с любым ключом) |
| `kroSearchByPersonName` | ~5126 | Поиск по найденному имени (теперь через каскад) |
| `kroSerperWebSearch` | ~5079 | Serper (платный, как запасной вариант) |

## Env переменные на Render

| Переменная | Статус | Зачем |
|---|---|---|
| `MISTRAL_API_KEY` | ✅ настроен | AI анализ |
| `TAVILY_API_KEY` | ❌ **нужно добавить** | Tavily веб-поиск, 1000/мес бесплатно |
| `GOOGLE_CSE_KEY` | ❌ **нужно добавить** | Google Custom Search, 3000/мес бесплатно |
| `GOOGLE_CSE_ID` | ❌ **нужно добавить** | ID поискового движка Google CSE |
| `SERPER_API_KEY` | скорее всего НЕТ | платный, заменён каскадом |

### Как получить TAVILY_API_KEY (самый простой вариант):
1. Зайти на [app.tavily.com](https://app.tavily.com)
2. Зарегистрироваться (Google/GitHub аккаунт)
3. Скопировать API Key со страницы Dashboard
4. В Render → Dashboard → `crypto-academy-pro` → Environment → Add Variable: `TAVILY_API_KEY` = ключ

### Как получить Google CSE (если Tavily не хватит):
1. [programmablesearchengine.google.com](https://programmablesearchengine.google.com) → New search engine
2. В поле "Sites to search" написать `*` (весь интернет)
3. Скопировать Search engine ID → это `GOOGLE_CSE_ID`
4. [console.cloud.google.com](https://console.cloud.google.com) → APIs → Custom Search API → Enable → Credentials → Create API Key → это `GOOGLE_CSE_KEY`
